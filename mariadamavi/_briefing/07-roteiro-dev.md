# 07 — Roteiro de desenvolvimento (seção por seção)

Vamos construir **uma seção por vez**: monta, revisa no navegador (desktop + celular), ajusta
e só então passa para a próxima.

Stack sugerida: HTML + CSS + JS puro (ou Vite) com GSAP + ScrollTrigger para as animações
de scroll. Um arquivo de tokens (`02-design.md`) vira o CSS base.
